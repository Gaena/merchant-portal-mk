# Правила Разработки и Взаимодействия (Project Rules)

- **Обязательное Согласование Изменений Кода**: Перед внесением любых изменений в файлы исходного кода или конфигурации проекта ОБЯЗАТЕЛЬНО:
  1. Подробно описать планируемые изменения, затрагиваемые файлы и их причину.
  2. Запросить явное подтверждение у пользователя.
  3. Не выполнять редактирование файлов до получения подтверждения от пользователя.
- **Обязательное Постоянное Обновление Файлов Агента и Документации**: При внесении абсолютно любых изменений в код, архитектуру, навигацию, интерфейсы или API проекта ОБЯЗАТЕЛЬНО немедленно актуализировать все связанные файлы агента (включая `.agents/workflows/*`, описания модулей и структурные карты проекта).
