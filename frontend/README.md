# MP Merchant Portal — Frontend Module

Реализация личного кабинета мерчанта на базе React 18, TypeScript, Vite, Tailwind CSS и Material UI.

Подробное руководство по архитектуре, маршрутам и правилам сквозной интеграции с бэкенд-микросервисами зафиксировано в документе:
👉 [frontend.md](file:///Users/salayevim/IdeaProjects/mp/.agents/workflows/frontend.md)

## Команды запуска:

```bash
# Установка зависимостей
npm install

# Запуск локального dev-сервера (порт 3000)
npm run dev

# Продакшн сборка
npm run build
```
